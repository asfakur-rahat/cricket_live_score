# cricket_live_score example

A home page with every widget in the package:

- the score ticker, with a switch between rotate and news crawl,
- a "Live now" inline carousel, with a switch between snap and free scrolling,
- the popup carousel, the live score screen and the bottom sheet,
- the floating match button.

It also has switches for System, Light and Dark themes, for screen-based scaling, and for live data. Live data comes from cricketdata.org's widget feed; turn it off to use offline sample data.

```sh
flutter run
```
